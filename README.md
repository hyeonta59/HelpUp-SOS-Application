# HelpUp SOS Application

## Overview
위급 상황 시 사용자가 빠르고 직관적으로 구조 요청과 위치 정보를 전송할 수 있는 안드로이드 기반의 긴급 대응 애플리케이션입니다. 
응급 상황에서 보호자 및 지정된 연락처로 신속하게 도움을 요청할 수 있도록 설계되었습니다.

## Key Features
- 사용자 맞춤형 SOS 호출 방식 설정 (버튼 인터페이스 등)
- 긴급 메시지 전송 기능 (SMS 기반 연동)
- 위치 정보 및 상세 위치 데이터 전송 기능
- 응급 상황에서 지연 없는 접근성을 고려한 UI/UX 디자인

## Tech Stack
- Language: Java / Android
- Environment: Android Studio
- APIs: SMS Manager API, Location Services

## My Contribution
- SOS 호출 로직 설계 및 구현 총괄
- 사용자 맞춤형 설정 및 긴급 메시지·위치 전송 기능 개발
- 안드로이드 애플리케이션 UI/UX 구조 설계

## Motivation
응급 상황에서는 사용자의 상태나 환경에 따라 빠르고 다양한 호출 방식이 필요하다고 판단하여, 직관적이고 개인화된 긴급 대응 시스템을 구축하고자 본 프로젝트를 기획하였습니다.

## Expected Impact
- 고령자나 취약 계층 등 다양한 사용자 환경에서 활용 가능한 맞춤형 응급 대응 솔루션으로 확장 가능
- 위급 상황 시 골든타임 확보 및 신속한 구조 협조 체계 마련에 기여
